# Publication and access checklist

## Package contents

Distribute the files in this folder as one repository/release. Keep the MATLAB entry point, its `QuasiOptical*.m` dependencies, the HTML guides, and CSV templates together. The symbolic tensor page is a standalone companion, not a substitute for the MATLAB app. Synthetic examples generated by the app are demonstrations and are not experimental measurements.

## Compatibility and licensing

The README records the project's tested MATLAB releases and minimum target. The app uses MATLAB UI, graphics, table, and numerical functionality; it does not intentionally call specialized RF or antenna toolbox APIs. MATLAB Online Basic includes MATLAB and a subset of toolboxes, not every product available to licensed users. Validate the complete app on the Basic offering before claiming Basic compatibility. Availability of MATLAB Online and Focused View depends on MathWorks account, license, and sharing configuration. No hosted deployment or public anonymous runtime is promised.

## Publish once, distribute through channels

1. Create one public GitHub repository from this package. Review the files and license before making it public; do not include the workspace's proposal folders, archives, or unrelated root-level copies.
2. Create a numbered GitHub release with a source ZIP (and an `.mltbx` only if a tested toolbox package is intentionally produced). GitHub Pages is available for public repositories on GitHub Free, subject to its usage limits; use it for project documentation, not as an application runtime.
3. Publish the repository on MATLAB File Exchange using the MATLAB and Simulink Integration for GitHub. Prefer the GitHub Releases connection so the listing tracks stable releases. The integration requires installing/authorizing the GitHub App and selecting repository access.
4. For MATLAB Online, use the supported GitHub workflow to open the repository and run the MATLAB entry point. Validate the current MathWorks instructions and access for a non-owner account. Focused View is a presentation mode for an eligible MATLAB Online session; it is not a separate deployment host.
5. MATLAB Drive can hold or share a copy of project files with collaborators. Treat shared Drive access as account-based collaboration, not anonymous public hosting.

## Verify cost and limits before advertising

GitHub repository hosting and Pages can be used at no charge for eligible public repositories, subject to GitHub terms and quotas. MathWorks currently describes MATLAB Online Basic as free with 20 hours per calendar month, 5 GB MATLAB Drive storage, and MATLAB plus nine listed products. Product availability and account entitlements can change. File Exchange has no stated submission fee in its publishing guide, but account and terms apply. Therefore do not advertise the complete workflow as universally "$0" until each service/account path is checked; there may be no service fee while user license eligibility, usage limits, and third-party costs still apply.

## Account-side release checklist

- [ ] Create/confirm GitHub account and public repository; review included content and license.
- [ ] In Settings → Pages, select GitHub Actions as the source. The Publish project site workflow builds the static site from `main`. Use Run workflow for a manual redeploy.
- [ ] Create a versioned release and verify its source archive downloads and opens.
- [ ] Sign in to MATLAB Central, install/authorize the MATLAB and Simulink GitHub App, select this repository, and publish the File Exchange listing.
- [ ] Test opening the released source in MATLAB Online with a Basic account and run `QuasiOpticalBistatic3D`.
- [ ] Check Focused View in that eligible session and confirm instructions for users.
- [ ] If sharing through MATLAB Drive, verify the recipient permissions and document sign-in requirements.
- [ ] Recheck links, version numbers, usage limits, license, and compatibility statements for every release.
