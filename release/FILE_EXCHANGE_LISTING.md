# MATLAB File Exchange listing draft

**Title:** Quasi-Optical 3D: Material Simulation and S-Parameter Retrieval

**Summary:** MATLAB app for quasi-optical reflection/transmission simulation, scalar S-parameter material retrieval, illumination diagnostics, and symbolic tensor/acquisition planning.

**Description:** See the repository README for MATLAB compatibility, installation, example provenance, model assumptions, and limitations. Synthetic examples are demonstrations and are not measured data. The symbolic tensor workspace is a planning/specification interface, not a numerical tensor retrieval engine. MATLAB Online access depends on MathWorks account and product eligibility.

**Tags:** MATLAB app, quasi-optics, material characterization, S-parameters, electromagnetic simulation, NRW, free-space measurement

**Source:** Link the public GitHub repository through the MATLAB and Simulink Integration for GitHub. Select the GitHub Releases update source for stable versions. Attach the tested ZIP package to each numbered release; do not advertise an `.mltbx` until one has been built and tested.
